<objective>
Build the DATABASE write path for offers: a new migration `staff_app_0008` adding (1) `public.staff_app_create_offer(...)` — a SECURITY DEFINER RPC that gates on `is_org_writer`, atomically quick-creates a gig when needed, generates a 256-bit token, stores only its sha256 hash, and returns the raw token exactly once; and (2) `public.staff_app_gigs` — a security_invoker view to list existing gigs for the pick step. ## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated client → public.staff_app_create_offer | Franco's JWT crosses into a SECURITY DEFINER function where RLS does NOT apply |
| anon → public schema | Postgres auto-grants anon on new public objects; must be explicitly revoked |
| RPC → staff_app.offers/gigs | The only sanctioned write path into org-owned tables |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-3-01 | Elevation | anon calling staff_app_create_offer | mitigate | Explicit `REVOKE ALL ... FROM PUBLIC, anon; GRANT EXECUTE TO authenticated;` (WR-05); verified live via has_function_privilege('anon',…)=false |
| T-3-02 | Tampering | writer passes a gig_id / staff_profile_id from another org | mitigate | RLS does not apply inside SECURITY DEFINER → validate `organization_id = v_org` on every SELECT/INSERT in the RPC (org forced from the fixed constant, not from input) |
| T-3-03 | Information disclosure | raw token leaking to a column or log | mitigate | Only `token_hash` (sha256) persists; raw token returned once in the jsonb and never stored/logged; harness asserts hash-at-rest |
| T-3-04 | Elevation | anon reading gig list via the new public view | mitigate | `REVOKE ALL ON public.staff_app_gigs FROM anon;` — security_invoker keeps RLS `is_org_member` on the base table |
| T-3-05 | Spoofing | forged writer identity | mitigate | Gate is `staff_app.is_org_writer(auth.uid())` which resolves the real caller JWT even inside SECURITY DEFINER (verified pattern from 0003) |
| T-3-SC | Tampering | search_path hijack of the definer function | mitigate | Pinned `SET search_path = staff_app, public, pg_temp` + schema-qualified `extensions.*`; get_advisors confirms no `function_search_path_mutable` finding |
</threat_model>
