## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| open signup → dashboard | Any Google/OTP login is a valid `auth.users` session; authentication ≠ authorization |
| browser → server | Service-role key must never cross to the client |
| new Vercel domain → shared auth | Redirect-URL allowlist change is a shared-project auth touch |
