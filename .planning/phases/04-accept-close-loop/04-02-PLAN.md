| candidato sin cuenta (teléfono) → /o/[token] | ruta pública, sin sesión; el token de 256-bit es la única credencial |
| GET (render) vs POST (mutación) | el GET sólo lee (flip viewed benigno); sólo el POST acepta/rechaza |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-4-06 | Tampering | bot de preview de email/WhatsApp dispara accept | mitigate | accept/decline SÓLO por Server Action POST (D-02); GET sólo llama get_public_offer (flip viewed, benigno) |
| T-4-07 | Tampering | doble-tap / replay del token duplica crew | mitigate | `accept_offer` guard `status IN ('sent','viewed') AND expires_at>now()` + crew `ON CONFLICT DO NOTHING` (idempotente, 0003); botón deshabilitado en vuelo |
| T-4-08 | Information Disclosure | fuga de PII de otros postulantes en la página pública | mitigate | render SÓLO del payload de get_public_offer (first_name + oferta/gig/org); sin segunda query, sin email/tel/cv/documento (Pitfall 7) |
| T-4-09 | Information Disclosure | token crudo en la URL / logs | accept | el token es la credencial portadora por diseño (256-bit, hasheado en reposo); no loguearlo, `rel="noopener"` en links externos; sólo viaja por HTTPS |
| T-4-10 | Elevation | service-role filtrado en la ruta pública | mitigate | usar sólo el cliente server (anon); grep-negativo de `createServiceRoleClient`/`supabase/admin` en page y actions |
